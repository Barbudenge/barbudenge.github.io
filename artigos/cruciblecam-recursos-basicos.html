CrucibleCam: an introduction to its basic features

By Artur Henrique de Freitas Avelar · Published November 27, 2026 · Watch on YouTube

This article accompanies the video above, which introduces the basic features of CrucibleCam through a practical example of radial cam design. The demonstration follows the principal stages of the process, from defining the follower motion to correcting discontinuities in the resulting kinematic curves.

In this article
  1. Defining the motion cycle
  2. Selecting motion laws and generating the profile
  3. Automatic search and comparison of solutions

Defining the motion cycle

The first step is to specify the desired follower motion. In the main interface, the user enters the angular interval and displacement change for each segment of the cycle. The segments are arranged until their angular intervals complete one revolution of the cam (360°).

This representation makes it possible to define the rise, return and dwell stages according to the motion required by the mechanism.

Selecting motion laws and generating the profile

When the user selects a displacement curve for each segment, CrucibleCam displays only the options compatible with the current design and the selections already made. As the motion laws are assigned, the remaining choices become more restricted, simplifying the construction of a feasible sequence.

The cam profile is calculated immediately, allowing the user to examine its geometry and inspect the displacement, velocity, acceleration and jerk (SVAJ) curves for discontinuities. CrucibleCam currently supports radial cams with flat-faced and roller followers.

Automatic search and comparison of solutions

Instead of selecting every motion law manually, the user can request an automatic search. The software identifies feasible combinations of displacement curves for the specified angular intervals and follower displacements.

The results can be sorted according to different design criteria. This facilitates the comparison of alternatives and helps the designer select a configuration that is better suited to the intended application. A feasible combination, however, does not necessarily guarantee continuity at all segment junctions.

Correcting discontinuities

In the example shown in the video, the selected combination presents an acceleration discontinuity between segments. Such an abrupt change can produce undesirable dynamic effects, increasing vibration and loads and potentially reducing the service life of the mechanism.

CrucibleCam provides a dedicated discontinuity-correction tool. The video demonstrates two approaches:

  • Adjusting angular intervals (β): the software redistributes the segment angles while retaining the specified displacement changes.
  • Adjusting follower displacement (ΔL): the software changes the displacement increments while retaining the specified angular intervals.

In both cases, the cam profile and kinematic curves are recalculated to reflect the corrected solution. The designer can then assess whether the changes are consistent with the mechanism's functional requirements.

The demonstration illustrates how CrucibleCam integrates the main stages of cam design in an interactive environment, making it easier to investigate motion laws, compare alternatives and refine a design.
